# AI Agent 职业规划手册

## 2026 — 2028 独立开发者成长路线（V2 修订版）

- **职业定位**：AI Agent Infrastructure / Trust / Commerce Engineer
- **核心目标**：从全栈开发者，逐步成长为能够解决"Agent 如何安全、可信、可支付地执行真实任务"的专业开发者。
- **版本**：2026 年 9 月（V2）
- **使用方式**：打印后作为年度路线图 + 月度执行清单 + 阶段复盘手册

> **V2 更新说明**：在 V1 基础上，补充了 ① 协议选型弹性检查 ② 具体获客与曝光渠道 ③ 结合工作室资源的时间安排 ④ 财务预期与工作室关系 ⑤ 风险资金实验的完全隔离记录，共五处调整。

## 一、我的职业总路线

这不是"学完一堆技术"的学习计划，而是一条以 **技术能力 → 可验证作品 → 社区影响力 → 第一笔行业收入 → 稳定收入 → 主业迁移** 为核心的职业路线。

最终职业标签：AI Agent 基础设施 / 信任 / 商业化方向工程师。Blockchain 是重要技术手段，但不把自己限制成"区块链工程师"。

> **【V2 新增】** 这条主线以个人技术能力建设为核心，同时会尽量调动工作室现有资源（人手、客户关系）来加速推进，而不是把它当成纯粹业余时间的副业——具体安排见第三节。

| 阶段 1 | 2026 Q4 | Identity + Wallet + Payment | 0～1,000 元/月 | Agent Passport + AgentPay |

## 二、必须遵守的 7 条原则（V2：新增第 7 条）

1. **不裸辞**：现阶段工作室的经营收入是现金流和安全垫。
2. **主线 80%，收入分支 20%**；收入项目尽量服务主线。可视工作室实际人手情况，动态调整个人能投入到主线的整块时间比例。
3. **少做"大平台"**，先做小工具、小 API、小产品，把周期控制在 2～6 周。
4. **每学一个技术**，必须留下可运行 Demo、GitHub Repo 或技术文章。
5. **不追热点币、不做 NFT/发币/投机交易**，把 Blockchain 当作 Agent 基础设施的技术能力。如需验证加密货币交易策略，一律使用完全独立的风险资金，按第二十二节单独记录，不占用主线的时间预算和收入目标。
6. **每季度必须有一个公开成果**；每半年验证一次市场价值。
7. **【V2 新增】** 每个季度检查点，除了检查自己有没有学完技术，必须额外检查一次：当前采用的协议/标准在过去三个月的行业采用趋势有没有变化，是否需要调整技术选型——协议还在快速演变，计划要允许根据事实调整，而不是不管环境变化死磕原计划。

## 六、第一阶段收入分支与获客渠道（V2 大幅扩充）

优先顺序：① Hackathon/Bounty → ② Agent API → ③ Agent/Web3 相关小型技术服务 → ④ 小型 AI 工具。

原则：如果项目只能赚一次钱且和主线完全无关，降低优先级；如果能同时形成代码、案例、用户、文章和收入，即使收入不高，也值得做。

**【V2 新增】具体渠道清单：**

**① Hackathon/Bounty 渠道：**
- 交易所/生态方举办的 Agent 相关黑客松（如币安 Agent OS、OKX Web3 开发者挑战赛类型的场次）
- Devpost 平台上的 AI Agent 赛事
- 以太坊生态的线下/线上黑客松活动
- 报名前留意参赛的地域限制条款

**② Grant 渠道：**
- 以太坊基金会开发者资助计划
- Base、Solana 等 L1/L2 生态的 builder grant
- 优先申请和当前月度项目（Agent Passport / AgentPay 等）直接相关的小额资助，而不是大型概念性提案

**③ 曝光与信誉渠道：**
- GitHub 开源：每个项目要求 Repo + README + 架构图 + 在线 Demo + 技术文章（呼应第十五节作品集路线）
- X（推特）"公开建造"：定期发布技术进展、踩过的坑、行业观察
- DAO 的 Discord/Telegram：留意项目方社区里流转的远程贡献机会

**④ 接单渠道：**
- Web3.career、CryptoJobsList 等垂直招聘平台
- DAO 远程贡献者角色
- 工作室现有客户中，寻找可以"顺带用上 Agent 能力栈"的需求，把主线能力嵌入工作室常规业务，一举两得

## 二十、第一性原则

你最终真正要建立的，不是某个框架的熟练度，而是一套能力：让一个 AI Agent 拥有身份 → 获得授权 → 安全调用工具 → 管理风险 → 与其他 Agent 协作 → 自动支付 → 留下审计记录。

这套能力越完整，你越不依赖某一个模型、协议或区块链项目。模型会变化，协议会变化，但"Agent 如何安全地执行真实世界任务"这个问题会持续存在。

**②** 拿工作室当前的月均/年均收入做基准（______________ 元/月），2028 年 Q4 决策时（见第十一节），把"新赛道收入"和"工作室收入"放在同一张表里对比，而不是孤立看新赛道数字好不好看。

## 二十二、风险资金实验记录（V2 新增，与主线完全隔离）

本节记录的内容，与本手册第一至二十一节的 AI Agent 职业主线完全隔离——不共享时间预算，不共享现金流账户，不计入任何阶段性收入目标或 Go/No-Go 判断。

**隔离原则：**

- **资金隔离**：只使用明确划出的、完全可以承受全部损失的风险资金，与工作室经营账户、AI Agent 主线的收入/支出账户物理和记账上完全分离。
- **时间隔离**：不占用第三节和第五节里为 AI Agent 主线安排的时间预算，只使用主线之外的时间。
- **决策隔离**：这条线的盈亏、进展，不作为 AI Agent 主线 Go/No-Go 检查点（第十七节）的判断依据，两条线互不影响彼此的推进决定。
- **合规前提**：在投入任何实际资金规模化操作之前，先完成一次同时了解中国大陆和新加坡跨境金融监管的专业律师咨询，把资金链路（境外交易主体 → 个人身份 → 收益形式 → 是否汇回及如何汇回）过一遍，书面记录咨询结论和日期，作为后续操作的前提条件，而不是事后补救。
